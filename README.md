# Visited Pages

**A Firefox extension for marking pages as visited, highlighting links, and organizing a personal collection of saved URLs.**

[**Install Visited Pages from Mozilla Add-ons**](https://addons.mozilla.org/pl/firefox/addon/visitedpages/)

Visited Pages lets you mark webpages and links as visited without needing to open them. It keeps a searchable list of the URLs you have marked and lets you give them a different link color from pages recognized as visited by Firefox's browsing history.

> **Note:** Marking a page in Visited Pages does not add it to Firefox's browsing history. The two sets of links are tracked and colored separately.

## Features

- **Mark or unmark pages:** Use the right-click menu on a webpage or link, or add multiple URLs at once.
- **Custom link colors:** Choose separate colors for Firefox-history links and links saved in Visited Pages, including links on dynamically updated websites.
- **Dashboard and sidebar:** Browse and search saved URLs; manage titles, notes, and tags.
- **Archive:** Restore deleted entries or remove them permanently, with configurable retention settings.
- **Statistics:** Explore saved-page activity, frequently saved websites, tags, and other trends.
- **Import and export:** Export JSON or CSV backups; import supported JSON, CSV, TXT, and HTML bookmark files.
- **Backups:** Create backups manually or schedule automatic JSON backups.
- **Optional experimental feature:** Retrieve missing page titles in the background, without opening tabs. This feature is disabled by default.

## Getting started

1. [Install the extension from Mozilla Add-ons](https://addons.mozilla.org/pl/firefox/addon/visitedpages/).
2. Right-click a webpage and select **Mark visited page**, or right-click a link and select **Mark linked page**.
3. Open the Visited Pages dashboard or sidebar to find and organize your saved pages.
4. Open **Settings → Link colors** to configure link highlighting.

## Privacy

Your saved-page collection and settings are stored locally in Firefox. No account is required. If you enable the experimental title-retrieval feature, the extension makes requests to the saved websites to look up missing titles. Backups are saved to files that you control.

## Compatibility

Firefox **128 or newer**.
